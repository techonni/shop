# Techonni shop

Art prints. GitHub Pages. Custom domain: `shop.techonni.com`.

## DNS (Hostinger)

Add a CNAME record:

- Host: `shop`
- Points to: `techonni.github.io`

Then in the GitHub repo: Settings → Pages → Custom domain `shop.techonni.com` (CNAME file is already in the repo).
